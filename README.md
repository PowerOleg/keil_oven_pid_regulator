## Heater PID Control. Программа для плавного нагрева и поддержания заданной температуры. ПИД регулятор.

Главная логика формирования управляющего сигнала ПИД регулятора располагается в функции void Heater_on(float setpoint, float temperature_c).

<h2>Мои выводы</h2>
<ol>
  <li>Пропорциональная ошибка (<code>e</code>) — основной вклад для формирования управляющего сигнала, потому что значение движется от большого значения всегда к нулю. 
Например решили останавливать нагрев за 5 градусов до уставки, для этого коэффициент <code>KP</code> сделаем 20. Тогда при e = 4. Мощность нагрева <code>power = KP * e</code> получаем 80% (20 * 4). При e = 3 получаем 60% и т.д. Если останавливать нагрев за 10 градусов, то <code>KP</code> приняли бы равным 10.</li>
  <li>Интегральная составляющая только вносит инерционность, следовательно, я её минимизировал. Однако если бы моя печка работала на улице, где значение потери тепла изменяется во времени, то интегральная составляющая бы пригодилась. Когда температура долго держится ниже уставки, интегральная составляющая растет. Это позволило бы увеличить мощность при повышенных потерях тепла.</li>
  <li>Дифференциальная составляющая <code>derivative</code> — это элемент сглаживания сигнала (противодействие пропорциональной составляющей).</li>
</ol>

Особенность системы: 
Экспериментальные данные, полученные в осенних условиях, демонстрируют значимую величину тепловых потерь системы даже при эксплуатации в помещении. В целях компенсации этих потерь в структуру ПИД‑алгоритма интегрирован коэффициент <code>K_ENVIRONMENT</code>, обеспечивающий дополнительное увеличение мощности нагревательного элемента.
